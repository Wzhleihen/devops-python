## 🧠 核心知识（底层原理）
- `reduce` 是“二元函数 + 可迭代对象”的折叠过程。  
- `partial` 会预先绑定一部分参数，后续调用时只需提供剩余参数。  
- 一旦某参数已被位置或关键字绑定，再次传同名值会触发冲突。  
- `lru_cache` 通过记忆化缓存递归结果，将指数级重复计算压缩为线性级别复用。

## ⚠️ 问题 / 坑（真实错误案例）
### 案例：`add() got multiple values for argument 'x'`
- 错误现象：Notebook 抛出 `TypeError: add() got multiple values for argument 'x'`。  
- 根因：`partial` 已经为 `x` 绑定值，后续调用又以位置/关键字重复传入 `x`。  
- 修正：统一参数传递策略（要么固定 `x` 后只传 `y`，要么不预绑定 `x`）。  
- 防再犯规则：偏函数创建后先看 `inspect.signature(new_func)`，再写调用。
