## 🧠 核心知识（底层原理）
- 作用域查找遵循 LEGB（Local → Enclosing → Global → Builtins）。
- 在函数内对变量执行赋值（如 `x += 1`）会让解释器将其视为局部变量；若先读取再赋值且未声明 `global/nonlocal`，会触发 `UnboundLocalError`。
- `range` 是可迭代对象（iterable）不是迭代器（iterator），`next(range(5))` 会报 `TypeError`，需先 `iter(range(5))`。
- 参数传递规则：位置参数必须在关键字参数之前，违反会触发 `SyntaxError`。
- `*args` 与 `**kwargs` 体现可变参数收集；容器解包（如 `add(*range(5))`）与直接传容器（`add(range(5))`）语义不同。

## 💻 关键代码（精简 + 行为解释）
```python
x = 5

def foo():
    x += 1
    print(x)

foo()
```

### 行为解释
- 该代码会报 `UnboundLocalError`。
- 原因：`x += 1` 被解释为“读取局部 x 并赋值给局部 x”，但局部 `x` 在读取前未绑定。
- 修正方案之一：
```python
x = 5

def foo():
    global x
    x += 1
    print(x)
```

## ⚠️ 问题 / 坑（至少一个错误案例）
### 案例：`next(range(5))`
- 错误现象：`TypeError: 'range' object is not an iterator`
- 根因：`range` 是 iterable，不是 iterator。
- 修正：
  - `it = iter(range(5))`
  - `next(it)`
- 防再犯规则：涉及 `next()` 时先确认对象是否实现迭代器协议；不确定就先 `iter()`。
