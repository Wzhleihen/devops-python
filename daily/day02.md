## 🧠 核心知识（底层原理）
- 递归函数必须有**收敛终止条件**，否则会无限展开。  
- 递推题建模关键是先写出状态转移，再决定顺推或逆推。  
- 对齐输出本质是字符串宽度控制：`rjust(width)` 负责列对齐，`center(total_width)` 负责行布局。  
- 涉及字符串索引时，`range` 上界和访问下标必须一致，否则极易触发越界。

## 💻 关键代码（精简 + 行为解释）
```python
def calculate_peaches(day):
    if day == 10:
        return 1
    return (calculate_peaches(day + 1) + 1) * 2

print(calculate_peaches(1))
```

### 行为解释
- 以第10天剩1个为递归基线。  
- 每向前推一天，执行“前一天 = (后一天 + 1) * 2”。  
- `calculate_peaches(1)` 得到第一天总桃子数 `1534`。

## ⚠️ 问题 / 坑（至少一个错误案例）
### 案例：三角打印中的字符串越界
- 错误现象：`IndexError: string index out of range`（见 `triangular_print.ipynb` 的 `triangular_print_v3`）。  
- 根因：循环从 `len(tail)` 开始访问 `tail[i]`，而有效下标最大是 `len(tail)-1`。  
- 修正：
  - 改为 `for i in range(len(tail)-1, -1, -1)`；或
  - 访问前先做边界判断。  
- 防再犯规则：凡涉及字符串/列表索引，先写“有效下标区间”再写循环。
