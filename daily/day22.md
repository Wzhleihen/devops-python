## 🧠 核心知识（底层原理）
- 继承让子类复用父类实现，并可按需覆盖方法实现多态。
- 双下划线属性会触发 name mangling：`__x -> _ClassName__x`。
- `super()` 按 MRO 查找最近父类实现，不是“固定父类名绑定”。
- `__dict__` 与类字典能直观看到属性落在哪一层。

## 💻 关键代码（精简 + 行为解释）
```python
class A:
    def __init__(self):
        self.__b = 100

class B(A):
    def showvalue(self):
        return self.__b

print(B().showvalue())
```

### 行为解释
- 上述代码会报：`AttributeError: 'B' object has no attribute '_B__b'`。  
- 原因是 `A.__b` 被改写为 `_A__b`，而 `B.showvalue` 中 `self.__b` 会找 `_B__b`。  
- 正确方式应访问父类暴露的方法/受保护属性，或显式使用 `_A__b`（仅教学演示，不推荐工程使用）。

## ⚠️ 问题 / 坑（至少一个真实错误案例）
### 案例：子类直接访问父类私有属性失败
- 错误现象：`B().showvalue()` 触发 `AttributeError: _B__b`。  
- 根因：误把 `__b` 当普通继承属性，忽略 name mangling 的类名绑定。  
- 修正：
  - 在父类提供 getter：`def get_b(self): return self.__b`；
  - 子类通过父类公开接口获取值。  
- 防再犯规则：继承体系里，双下划线默认只在声明它的类内部直接访问。
