## 🧠 核心知识（底层原理）
- `@logger` 在函数定义阶段执行，不是调用阶段才执行。  
- 包装器若不接收 `*args, **kwargs`，很难适配不同签名函数。  
- 未使用 `wraps` 时，外部拿到的是包装函数元数据。  
- `wraps(wrapped)` 会复制关键属性并保留 `__wrapped__` 链路。

## 💻 关键代码（精简 + 行为解释）
```python
from datetime import datetime
from functools import wraps

def logger(wrapped):
    @wraps(wrapped)
    def wrapper(*args, **kwargs):
        start = datetime.now()
        ret = wrapped(*args, **kwargs)
        end = datetime.now()
        print(f"运行时间：{(end - start).total_seconds()}")
        return ret
    return wrapper
```

### 行为解释
- `wrapper` 负责横切逻辑（计时、日志）。  
- `ret = wrapped(...)` 保证原函数行为和返回值不变。  
- `@wraps` 保留原函数名称和文档信息，利于调试与文档工具。

## ⚠️ 问题 / 坑（至少一个错误案例）
### 案例：装饰后函数名变成 `inner` / `wrapper`
- 错误现象：归档输出中 `print(add.__name__)` 显示 `inner` 或 `wrapper`。  
- 证据位置：`归档/2025/2025-12-02/demo01.ipynb`（初版与改进版单元输出）。  
- 根因：返回的是包装函数对象，默认元数据属于包装函数本身。  
- 修正：
  1. 过渡方案：手动复制 `__name__`、`__doc__`；
  2. 推荐方案：在包装函数上加 `@wraps(wrapped)`。
- 防再犯规则：只要写函数装饰器，默认先加 `@wraps`。
