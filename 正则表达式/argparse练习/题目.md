# 一、基础练习（理解 argparse）

### 练习 1：echo 命令

实现一个 `echo.py`

要求：

python echo.py hello world

输出：

hello world

要求：

- 支持参数
    

-n   不换行

示例：

python echo.py hello -n

输出：

hello

---

### 练习 2：wc 命令

实现简化版 `wc`

python wc.py file.txt

输出：

lines: 10  
words: 50  
chars: 300

参数：

-l   只统计行  
-w   只统计单词  
-c   只统计字符

示例：

python wc.py file.txt -l

---

### 练习 3：mkdir

实现：

python mkdir.py testdir

要求：

参数：

-p   自动创建父目录

示例：

python mkdir.py a/b/c -p

# 二、中级练习（CLI 设计）

---

### 练习 5：grep

实现：

python grep.py hello file.txt

输出包含 `hello` 的行。

参数：

-i   忽略大小写  
-n   显示行号

示例：

python grep.py hello file.txt -n

输出：

3: hello world  
8: hello python

---

### 练习 6：du

实现：

python du.py path

输出目录大小。

参数：

-h   human readable

输出：

10K  
2M  
1G
