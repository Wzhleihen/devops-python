## Why

当前仓库是 Python 学习练习仓库，已积累了章节目录、日期目录与练习内容，但目录组织存在时间与主题并存、命名不一致的问题，影响检索与复盘效率。现在需要在不破坏章节内容的前提下，建立稳定的归档与 daily 体系，支撑后续持续学习。

## What Changes

- 统一目录分层：保留现有中文章节顶层目录，新增 `归档/2025` 与 `daily`。
- 将现有日期目录统一迁入 `归档/2025`，并修正异常日期目录命名（`20225-12-04` → `2025-12-04`）。
- 明确后续规范：章节目录名保持中文；新增子目录/文件尽量使用英文命名。
- 设立 `daily/dayxx.md` 作为学习提炼入口（后续内容细化），与章节代码形成可追溯链接关系。
- 不对既有章节目录内部文件做迁移、改名或内容修改。

## Capabilities

### New Capabilities
- `learning-repo-organization`: 为学习仓库提供统一的目录组织与日常沉淀规范，包括归档、daily 与章节协作边界。

### Modified Capabilities
- None.

## Impact

- 影响范围：仓库目录结构与文档规范（README/AGENTS 可后续补充说明）。
- 不影响范围：章节目录内代码与 notebook 内容、运行逻辑、外部依赖。
- 主要风险：路径变化导致历史引用失效（通过限制迁移范围与保留章节目录不动降低风险）。
