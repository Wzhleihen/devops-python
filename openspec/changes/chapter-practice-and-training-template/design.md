## Context

当前学习流程已形成 day 输出，但强化训练题与答案缺少独立目录与统一规范，导致训练资产无法稳定复用。用户已确认采用“按章节管理”方案，并明确“归档先不用写”，即本次聚焦章节训练目录与 day 模板联动，不处理归档回链扩展。

## Goals / Non-Goals

**Goals:**
- 建立 `practice/` 与 `answers/` 的章节+难度分层目录规范。
- 定义统一题号与命名规则，确保题目与答案一一对应。
- 让 `daily/dayxx.md` 强化训练部分必须回链到题目和答案路径。
- 保持现有章节中文目录名称不变。

**Non-Goals:**
- 不改动归档目录结构与归档写入流程。
- 不一次性重写所有历史 day 内容。
- 不引入外部题库系统或数据库。

## Decisions

1. 目录组织采用“按章节 + 按难度分层”。
   - 结构：`practice/<章节>/{foundation,advanced,transfer}` 与 `answers/<章节>/{foundation,advanced,transfer}`。
   - 原因：用户优先强调章节训练聚合与检索效率。

2. 题号规则统一为 `p-xxx-topic`。
   - 题目：`p-001-safe-copytree.md`
   - 答案：`p-001-safe-copytree.answer.md`
   - 原因：便于 day 回链与后续自动生成。

3. day 模板强化训练字段设为硬性必填。
   - 必填：训练目标、训练任务、验收要求、答案路径。
   - 原因：保证“训练可执行 + 可验收 + 可对照”。

4. 逐步迁移策略：先新题新规范，再补历史。
   - 原因：降低一次性改造风险，避免影响当前学习节奏。

## Risks / Trade-offs

- [章节名与路径不一致] → 用模板校验与路径检查脚本阻断错误回链。
- [题号冲突] → 增加章节内题号唯一性检查。
- [答案质量不一] → 在模板中增加最小答案结构（思路+代码+边界说明）。
- [历史 day 未回链] → 先要求新 day 严格执行，历史内容分批补齐。
